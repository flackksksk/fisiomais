# Fisio+ — demo New Hera
npm install && npm run dev
Build: `npm run build` → pasta `dist` (Cloudflare Pages: build command `npm run build`, output `dist`).
Antes de publicar: adicionar fotos em public/images (hero.jpg, about.jpg), confirmar horário e nº de avaliações (src/data.ts), trocar SEU-DOMINIO.com.br em index.html e robots.txt.
